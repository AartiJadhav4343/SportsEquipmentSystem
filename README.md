# Sports Equipment Management System

Console-based Core Java project to issue and return sports equipment, like a library system.

## Concepts used
- OOPs (Inheritance, Abstraction, Polymorphism, Encapsulation)
- Collections (HashMap, TreeMap, ArrayList)
- Exception Handling (custom exceptions)
- Multithreading (overdue checker thread)

## Features
- Add / remove / search equipment
- Register students and staff
- Issue and return equipment with fine calculation
- View student list, staff list, issued items and member history

## How to run
Open in Eclipse and run `app/Main.java`.
